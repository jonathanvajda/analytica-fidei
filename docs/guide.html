Biblical Discourse Analysis Guide

Start discourse analysis with an exact source.

Create an English, Greek, or Hebrew practice project from the Projects drawer. These are authored examples, not Bible editions. The main workspace is one canvas containing words, propositions, brackets, and relationship labels. Projects and the contextual Inspector are optional side drawers; they are not steps in the analysis.

Controls are organized by purpose. The Settings cog contains zoom, fit-to-view, canvas widening, grammatical landmarks, and light/dark theme. Selecting a word automatically opens the Inspector, where Assign role, Anchor connective, and Add note are available when the selection permits them. Import, backup export, Mermaid preview/download, and project deletion are kept together in Projects.

Arrange words directly

Drag a word to snap it to a grid cell. Occupied cells clear automatically so words do not overlap. A word can move horizontally or onto another visual line within its proposition or unassigned source run. Dragging an adjacent unassigned word onto a proposition adds that missed word to its source span; dragging an edge word from a proposition onto a source block returns it to staging. If no source block is visible, select one or more edge words and choose Return to source. A correction cannot split or empty a proposition, and an affected explicit grammatical role must be removed first. Following propositions and enclosing brackets adjust to the new height.

Click words to select them; Shift-click selects a consecutive source range. Choose Create proposition to mark the selection. Focus a word and use arrow keys to nudge it; Shift-arrow moves four cells. Double-click or right-click a word for supplied annotations. The Inspector button also opens details for a selected word.

Select proposition checkboxes beside the words to Group selected or Connect selected. Group badges also have checkboxes, so a relationship can connect two propositions, a proposition and a group, or two groups. The editor names the participant role performed by the “From” unit and the role received by “To”; reverse the endpoints if those roles are backwards. Expand the relationship legend for every definition and role pair. Larger groups may contain smaller ones; partially overlapping groups are rejected. Click a relationship label to trace its directed connector; the focused relationship can then be edited or removed.

With a relationship focused, choose Trace connected argument to highlight every proposition and relationship reachable through the semantic graph. This temporary inspection view does not change the primary bracket outline or the stored analysis.

Use Edit on a discourse-group badge to revise its label without rebuilding the group. Its stable identity, proposition membership, nesting, relationships, and bracket placement are retained.

Undo/Redo (Ctrl/Cmd-Z, Ctrl/Cmd-Shift-Z, or Ctrl/Cmd-Y) reverse edits during the current session. Widen canvas adds horizontal grid space each time it is pressed; use the horizontal scrollbar to reach it. The expanded width is saved with the project. Reset positions restores default word flow without deleting the analysis. Zoom controls scale the grid while preserving saved positions. Touch dragging uses the same grid; swipe empty canvas space to scroll.

Use Dark theme in the canvas toolbar to switch the complete workbench presentation. The preference is retained in this browser and does not alter or become part of the analysis document.

When the active edition supplies lexical gloss annotations, use Show glosses to display them beneath their exact source words. The control says Glosses unavailable when the source package does not provide them. This presentation preference is retained locally and never invents glosses or changes the analysis.

Use Show grammatical landmarks when supplied part-of-speech annotations or accepted connective anchors are available. Finite verbs, connective cues, and other parts of speech can be enabled independently—show only verbs and connectives for a compact proposition skeleton. Compact symbols and patterned borders identify the classes; expand the legend in Settings for definitions and coverage counts. The overlay is presentation-only. It does not decode unknown morphology, invent missing annotations, or turn part of speech into an accepted grammatical role.

For pointed Hebrew text, Hide vowels and Hide cantillation independently filter combining marks from the canvas display. These controls remain hidden for non-Hebrew working texts. The original source token, its identity, and its saved annotations remain unchanged. Controls explicitly report when the active Hebrew text contains no marks of that kind.

The workbench is installable and caches its application shell and bundled SBLGNT edition for offline use. After the service worker finishes its initial installation, reloads and passage opening work without a network connection. Imported projects remain in browser-local IndexedDB; exporting backups is still recommended.

To record a connective cue, select one source word plus one proposition or discourse group, then choose Anchor connective. To anchor the currently focused relationship instead, clear proposition/group selection and select one source word. Classify the cue’s function in the Inspector. Every target records textual evidence without assigning the word again or automatically determining a relationship; remove the badge or use Undo to revise it.

To define an explicit grammatical constituent, select its source word or words and one proposition, then choose Assign role. Name it if useful and choose Subject, Predicate/verb, Object, or another role. To reuse it where the text leaves it implicit, select the target proposition without selecting words, choose Assign role, select the existing constituent, and save it as implicitly reused. Removing a role badge does not delete the source words or its reusable identity.

After assigning constituents to a proposition, select that proposition and choose Analyze modifier. Choose the modifier, its modified constituent, and a General, Attributive, or Predicative function. A Substantive adjective stands as a nominal and therefore has no modified target. Modifier assertions can be edited or removed; dependent roles cannot be detached until the assertion is removed.

To record an observation, select exactly one word or proposition and choose Add note. Classify it as General, Grammatical, Lexical, Discourse, or Interpretive. Proposition notes appear as canvas badges; word notes appear in the word Inspector. Use Edit to revise its category or text without changing its anchor. Notes persist with the project and participate in Undo/Redo.

A focused discourse relationship also offers Add relationship note. These notes explain the analytical decision without altering its type or direction; they can be edited and removed beside the relationship label and are cleaned up when the relationship is deleted.

The Inspector lists every reusable constituent after the first one is defined. Rename an item there to update its label everywhere it is used. Deletion remains disabled until its grammatical roles have been removed, preventing dangling implicit or explicit assignments.

Reusable constituents can also carry editable notes explaining an elliptical reading or other grammatical decision. These notes follow the canonical constituent across every explicit and implicit use and are removed with it when the unused constituent is deleted.

New projects choose a grid width for the current viewport. Existing saved projects keep their grid width and can scroll on smaller screens. Removing a proposition also removes its dependent groups and relationships. Ungrouping retains its propositions and unrelated semantic edges, while removing edges that used the deleted group itself as an endpoint. Undo history is session-only; the current positions are saved and included in backups.

Import a parsed passage

Use Import passage JSON with a record shaped like the following. This downloadable synthetic example contains two English words. For real biblical text, record the actual edition, release version, versification, and dataset provenance and licensing.

{
  "source": {
    "sourceId": "practice-import",
    "version": "1",
    "language": "en",
    "provenance": { "providerId": "local-example" }
  },
  "unitKey": "practice:1",
  "reference": { "display": "Practice phrase, not scripture" },
  "text": "People listen.",
  "records": [
    { "id": "w1", "text": "People", "start": 0, "end": 6 },
    { "id": "w2", "text": "listen", "start": 7, "end": 13 }
  ]
}

Optional record fields: language, lemma, morph, pos, gloss, and strongs. Add a top-level glossLanguage for glosses and morphologyScheme for morphology codes. Strong’s references must include G/H prefixes in this generic importer. fields can map the shared adapter’s field names to provider keys or tuple indices.

Offsets are half-open UTF-16 indices matching JavaScript strings. They must match the exact source token spelling and may not split a grapheme cluster. If offsets or source text are unavailable, omit them: tokens are displayed with separator spaces, without claiming those spaces reproduce the source. Token IDs are edition/version-specific. Changing segmentation requires a new source version.

The generic importer treats lemma as a lemma spelling. OSHB’s numeric/slash lemma attributes must first pass through the shared createOshbWordAdapter profile; do not put those codes into a lemma-spelling field. A dedicated corpus import pipeline is a next step.

Save, resume, and export

Projects save to IndexedDB after each successful edit. Open saved projects from the left panel after returning to the site. If storage is unavailable or a write fails, the UI reports that state; export a backup before closing. Browser storage is tied to this browser and site origin.

Preview Mermaid shows deterministic flowchart source for the ordered propositions, nested groups, and directed discourse relationships. Download Mermaid saves the same source as an .mmd file. Mermaid captures the semantic outline, but does not reproduce freeform canvas coordinates.

Export backup writes a schema-versioned JSON analysis document. Open project backup validates it and opens a separate project, preserving the original. The current format is not yet RDF or JSON-LD.

What this foundation covers

Local projects, one integrated snapping canvas, direct word placement, manual contiguous propositions, nested non-crossing groups, explicit directed relationships, lexical inspection, Greek/Hebrew display, JSON backup and restore. Native buttons and checkboxes support keyboard use.

Still ahead: additional licensed Bible corpora, multiple passages per project, working/supporting editions, interlinear alignment UI, richer grammatical construction and editing, RDF/JSON-LD and image exports, rendered Mermaid preview, and richer bracket-label layout.
